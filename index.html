Connect Supabase

1. Create a project

Create your own project at supabase.com. Each person uses a separate project.

2. Run the setup SQL once

Open SQL Editor, paste this SQL, then click Run.

Setup SQL
Copy into SQL Editor
create table if not exists public.life_os_sync (
  id text primary key,
  data jsonb not null default '{}',
  updated_at timestamptz default now()
);

alter table public.life_os_sync enable row level security;
grant usage on schema public to anon;
grant select, insert, update on public.life_os_sync to anon;

drop policy if exists "TelOS read" on public.life_os_sync;
create policy "TelOS read" on public.life_os_sync
  for select to anon using (id = 'life_os_data');

drop policy if exists "TelOS insert" on public.life_os_sync;
create policy "TelOS insert" on public.life_os_sync
  for insert to anon with check (id = 'life_os_data');

drop policy if exists "TelOS update" on public.life_os_sync;
create policy "TelOS update" on public.life_os_sync
  for update to anon using (id = 'life_os_data')
  with check (id = 'life_os_data');

3. Paste your URL and key

URL: Integrations → Data API.

Publishable key: Settings → API Keys. Use the sb_publishable_ key, never a secret key.

Paste them here and click Verify & Connect.

Another device? Use the same URL and key. If prompted, choose Use cloud version.

Anyone with these connection details can read and change this plan. They are saved on this device.
