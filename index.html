Where to Find Your Supabase Credentials

API URL

  1. Log in to your Supabase dashboard
  2. Select your project
  3. Go to Project Settings → Data API
  4. Copy the Project URL (looks like https://xxxx.supabase.co)

Anon Key / Publishable Key

  1. Go to Project Settings → API Keys
  2. Find the anon public key (starts with eyJ...)
  3. Or if using Supabase Publishing, use your publishable key (starts with sb_publishable_...)
  4. Paste it into the key field above

Need a Supabase project?

Go to supabase.com, sign up, create a project, then run this SQL in the SQL Editor:

create table public.life_os_sync (
  id text primary key,
  data jsonb not null default '{}',
  updated_at timestamptz default now()
);

alter table public.life_os_sync enable row level security;
create policy "Enable all" on public.life_os_sync
  for all using (true) with check (true);
